Spotifast 0.13.2 keeps Windows from marking it as not responding in the tray, stops MilkDrop from stalling the window, reconnects playback by itself after a network drop, and keeps your playback approval when its port is busy. The Flatpak moves to a runtime that still gets security updates.

On Windows, pick the `.msi`. The setup program (`-setup.exe`) is still attached so that installs from 0.12.0 and earlier can update through it.

## New

- **Your screen's rate on the visualizer frame-rate dial, without opening MilkDrop first.** Spotifast now asks the monitor showing the window how often it refreshes. By @dennisgr7. (#893)
- **A header tint for custom palettes, and a header wash that scrolls with the page.** A palette's new `tint` colour gives page headers a wash when album art doesn't colour them, and the wash now scrolls away with the header instead of staying put. By @sasoder. (#752)

## Fixed

- **Windows no longer marks Spotifast as not responding while it sits in the tray.** By @crmne.
- **The window no longer stalls every 30 seconds with a large MilkDrop presets folder.** With Settings or MilkDrop open, listing thousands of presets froze the window for about 0.4 seconds every 30 seconds. They are now listed in the background. By @crmne.
- **MilkDrop no longer opens to a blank window on some Windows PCs.** A display set to "hardware default" reported 1 Hz, and MilkDrop could save that as its frame rate. Such reports are now ignored, and a frame rate saved that way is forgotten. This is probably what @Olafosboss saw. By @dennisgr7. (#896, #885)
- **Playback reconnects by itself after a network drop or waking from sleep,** using your saved approval, instead of asking you to set up playback again. Setting up playback also tries the saved approval before opening the browser. By @crmne; thanks @kakulukia and @Jaideepo7. (#818, #824)
- **A busy port 8898 no longer throws away your playback approval.** Spotifast now reserves the port before opening the browser, so another app holding it shows a clear message in Settings instead of a hung page and a lost approval. By @crmne; thanks @dams. (#899)
- **Windows may now keep your sign-in across restarts.** On some PCs Spotifast forgot every Spotify sign-in at restart. When Windows refuses to save a sign-in the usual way, Spotifast now saves it in a way that also survives a restart, and the log names the error. If you still have to sign in after every restart, please report it with your log. By @crmne; thanks @sasirmishamsi, @HyPeRXKo and @Th3H3ll50. (#815, #748, #803)
- **Your playlist order follows changes made in Spotify's other apps.** Spotify custom order is read again when you come back to the window, instead of only at launch. By @SametKaras; thanks @loessy. (#749, #683)
- **x64 Windows says why Spotifast can't start without OpenGL 2.0,** for example in a virtual machine without a graphics driver, instead of quitting silently. By @crmne.
- **Task Manager shows "Spotifast"** instead of "A native Spotify client". By @crmne.
- **Uninstalling removes leftover update folders,** and updates clean up the ones earlier updates left behind. By @crmne.
- **The Flatpak gets security updates again.** It now uses the Freedesktop 25.08 runtime, as 24.08 has reached end of life. By @crmne; thanks @uAliAmer. (#886)
- **Spanish shows ready playback as "Listo".** By @dennisgr7. (#900)
